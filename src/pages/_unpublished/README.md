# Unpublished

Pages created during the September 2026 SEO pass and withdrawn in the
restoration pass that followed. Astro does not route anything under a folder
whose name begins with `_`, so nothing here is built, linked, or listed in the
sitemap — the files are kept only so the work is not lost.

They were withdrawn for the same reason in each case: they were written for
search and answer engines rather than for a reader, leaning on worksheets,
matrices and checklists in place of the site's own voice, and several of them
could not be supported with real figures.

Republishing one means rewriting it in TripAxle's voice first, moving it back to
`src/pages/`, and adding it to `src/lib/page-dates.mjs` and the relevant hub.
